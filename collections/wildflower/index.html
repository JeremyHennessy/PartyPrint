Two easy games, no awkward setup

Play along with the presents

Give each player a bingo card and a pen before gifts are opened. Mark an item when that gift appears. A bundle can match several named items; repeated gifts mark the same square once. The center is free. Five marked squares in a row, column or diagonal wins.

The sample has one card. For a group, use the free generator to make up to 48 differently arranged cards. You can change the gift list, party title and theme there. The downloadable Wildflower sample is a fixed design, not an editable template.

Match the tiny animals

Print page 2 for each willing guest. Match each animal to its baby by writing a letter from the word bank. Use each letter once. Allow about five minutes, then use page 3 to check answers: one point per correct match. Keep the answer key with the host. Tied winners are welcome, and prizes are optional.

Get a good print the first time

  1. Choose Letter for 8.5 × 11 inch paper or A4 for 210 × 297 mm paper.
  2. Open the saved sample and check that it has three pages.
  3. Match your printer’s paper size and choose actual size or 100%. Turn off browser headers and footers.
  4. Print one test page before making guest copies. Plain paper is fine for games; use card stock only if your printer supports it.
  5. Print page 2 as often as needed, keeping page 3 separate for the host. Use the free generator for additional unique bingo cards.

The designs have mostly white backgrounds and do not need borderless printing. Grayscale works for the sample. PDF pages have been checked digitally; physical printer results can vary.
